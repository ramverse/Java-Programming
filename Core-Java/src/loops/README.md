# Java Loops

This folder contains Java programs for understanding  and practicing loops.

## Topics Covered

* `for` loop
* `while` loop
* `do-while` loop
* Nested loops
* `break`
* `continue`

## Files

* `ForLoop.java` — Basic `for` loop
* `WhileLoop.java` — Basic `while` loop
* `DoWhileLoop.java` — `do-while` loop
* `NestedLoop.java` — Nested loops
* `BreakStatement.java` — `break` statement
* `ContinueStatement.java` — `continue` statement


**Goal:** Understand loops and build a strong foundation for problem solving and DSA.
