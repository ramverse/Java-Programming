Key Concepts

Conditional statements allow a program to make decisions based on conditions.

if

Used when a block of code should execute only when a condition is true.

if-else

Used when there are two possible paths.

else-if

Used when there are multiple conditions to check.

Nested if

An if statement placed inside another if statement.

switch

Used when one value needs to be compared against multiple possible cases.
